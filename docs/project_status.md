# Project Status

ResumeIQ is currently a portfolio-ready MVP.

## Completed

- PDF, DOCX, TXT resume upload
- Direct pasted resume text input
- Job description parsing
- Local skill matching
- Required/preferred skill detection
- Match score and score breakdown
- ATS readiness checks
- Contact info extraction
- Explainable score evidence
- Tailored rewrite suggestions
- Downloadable Markdown report
- Optional NVIDIA/OpenAI-compatible rewrite enhancement
- Local fallback when no API key is configured
- FastAPI backend
- React/Vite frontend
- Calibration examples
- Automated backend tests
- Makefile shortcuts

## Best For

- GitHub portfolio project
- College project/demo
- Student resume tailoring
- Controlled testing with sample resumes and job descriptions
- Demonstrating explainable local NLP-style logic

## Not Yet Production SaaS

- No authentication
- No persistent user accounts
- No database
- No production deployment config
- No enterprise privacy controls
- Limited scanned-PDF support

## Recommended Future Improvements

- Screenshot-rich README
- Print/PDF report export
- Better scanned-PDF warning
- More skill taxonomy coverage
- Real deployment
- Optional user accounts and saved reports
